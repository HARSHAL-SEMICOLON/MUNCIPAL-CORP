# =============================================================================
#  LOCAL DEVELOPMENT -- use this one on your own machine.
# =============================================================================
#  `requirements.txt` is the DEPLOYMENT list and it installs
#  opencv-python-headless, which is correct for a server: a cloud host has no
#  display, and the headless build is smaller and avoids libGL entirely.
#
#  But headless OpenCV has no GUI functions compiled in at all, and `main.py`
#  opens a real window:
#
#      cv2.namedWindow(...) / cv2.imshow(...) / cv2.waitKey(...)
#
#  With the headless build those raise
#      cv2.error: The function is not implemented.
#  which reads like a broken install rather than the wrong wheel.
#
#  So: this file is identical to requirements.txt except that it installs the
#  FULL opencv-python. Never install both into the same environment -- they
#  overwrite each other's `cv2` module and whichever landed last wins.
#
#      python -m venv .venv
#      .venv\Scripts\activate          (Windows)
#      pip install -r requirements-local.txt
#      python main.py
# =============================================================================
